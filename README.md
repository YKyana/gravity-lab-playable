# Gravity Lab

**Pick. Boost. Survive.**

Gravity Lab is a lightweight browser physics game designed for short, replayable rounds. Pick one of three contenders, launch the race, and use a single timed boost to help your ball survive the obstacle course.

## Play

The game runs directly in a modern desktop or mobile browser with no installation required.

## Current features

- Three selectable contenders
- Physics-based obstacle course
- One tactical BOOST per round
- Win-streak and best-streak tracking
- Responsive portrait layout
- Synthesized sound effects
- No external runtime dependencies

## Roadmap

- Additional power-ups and traps
- Daily seeded challenge
- YouTube Playables SDK integration
- YouTube cloud saves and score submission
- English localization polish and accessibility testing

## Technology

HTML5 Canvas, CSS, and vanilla JavaScript.
